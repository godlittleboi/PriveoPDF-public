# Support / Assistance

PriveoPDF est fourni sans garantie de support individuel, de délai de réponse ou
de correction. La dernière version officiellement publiée est la seule version
destinée à recevoir des correctifs ; une branche, une archive de PR ou une
révision source non publiée n'est pas une version prise en charge.

## Canaux prévus

- Questions, aide et idées : GitHub Discussions, uniquement après son activation
  manuelle par le propriétaire.
- Bugs reproductibles : GitHub Issues, uniquement après leur configuration sur
  le futur dépôt public propre.
- Vulnérabilités : le canal confidentiel décrit dans `SECURITY.md`, seulement
  après vérification de son fonctionnement. Ne jamais utiliser une Issue ou une
  Discussion pour une vulnérabilité non corrigée.

L'absence d'un de ces canaux bloque la publication ; aucune adresse électronique
ou adresse postale n'est présumée par ce document.

## Informations sûres à fournir

Indiquer la version, le système, le mode d'installation, les étapes minimales et
le résultat attendu/observé. Utiliser seulement un PDF artificiel non sensible et
redistribuable si une pièce jointe est indispensable.

Pour une Bêta, le rapport local créé depuis `Options > Diagnostic Bêta` peut
remplacer la saisie manuelle de la PR, du SHA et des versions techniques. Il
doit être relu avant partage et reste insuffisant sans étapes de reproduction
si la structure particulière d'un PDF déclenche le défaut.

Ne transmettre aucun PDF utilisateur, contenu confidentiel, mot de passe, jeton,
clé, chemin personnel complet, journal non relu, donnée personnelle inutile ou
code externe. Un retour ne promet ni réponse, ni implémentation, ni calendrier,
ni rémunération, ni autre contrepartie.

---

PriveoPDF comes with no promise of individual support, response time, or fix.
Only the latest officially published version is intended to receive fixes.
Planned Discussions are for help and ideas, Issues are for reproducible bugs,
and potential vulnerabilities must use the confidential route in `SECURITY.md`.
Those channels must be configured and tested by the owner before publication.

Never send a user PDF, confidential content, credentials, a private path, an
unreviewed log, unnecessary personal data, or external code. Feedback creates
no promise of response, implementation, schedule, payment, or consideration.
