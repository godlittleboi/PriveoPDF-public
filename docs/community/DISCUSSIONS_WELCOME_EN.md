# Welcome to PriveoPDF Discussions

This space hosts questions, ideas, interface feedback,
comments on published source, and non-sensitive demonstrations. PriveoPDF
is open source under Apache License 2.0 (`Apache-2.0`); third-party components
retain their own licenses.

The initial phase accepts comments, not code. Do not send patches, diffs,
external pull requests, substantial source files, third-party code, user PDFs,
secrets, private paths, confidential information, or unnecessary personal
data. No CLA is active.

Report reproducible bugs here; the maintainer can turn them into tracked Issues. Never disclose a potential vulnerability
here: follow `SECURITY.md` and wait for a working confidential route. A comment
does not promise a response, implementation, delivery date, payment, or other
consideration.
