# Bienvenue dans les Discussions PriveoPDF

Cet espace, lorsqu'il sera activé, accueillera les questions, idées, retours
d'interface, commentaires sur le code publié et démonstrations non sensibles.
PriveoPDF reste un logiciel propriétaire ; l'instantané consultable est
source-disponible et n'est pas open source.

La phase initiale accepte des commentaires, pas du code. N'envoyez ni patch,
diff, Pull Request externe, fichier source substantiel, code tiers, PDF
utilisateur, secret, chemin personnel, information confidentielle ou donnée
personnelle inutile. Aucun CLA n'est actif.

Utilisez les Issues pour un bug reproductible. Une vulnérabilité potentielle ne
doit jamais être publiée ici : suivez `SECURITY.md` et attendez qu'un canal
confidentiel fonctionnel soit indiqué. Un commentaire ne garantit aucune
réponse, implémentation, date, rémunération ou autre contrepartie.
