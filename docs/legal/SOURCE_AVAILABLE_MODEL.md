# Modèle de publication du code source

Statut : dépôt canonique privé ; publication future dans un dépôt propre séparé.

PriveoPDF reste un logiciel propriétaire. Le code détenu par PriveoPDF pourra
être publié pour consultation, étude et audit sous
`LicenseRef-PriveoPDF-Source-Available-1.0`, dont le texte contractuel est le
fichier racine `LICENSE`.

La licence autorise aussi l'installation et l'usage gratuit d'une version non
modifiée, à titre personnel ou pour les besoins professionnels internes d'une
personne ou d'une organisation. Elle n'autorise pas la modification, la
création d'œuvres dérivées, la redistribution, la revente ou la fourniture
comme service sans autorisation écrite distincte.

Ce régime est « code source consultable » / *source available*. Il ne satisfait
pas aux libertés de modification et de redistribution d'une licence open source
et ne doit jamais être présenté comme tel.

Les composants, ressources et corpus tiers restent exclusivement régis par
leurs licences. Les exécutables officiels peuvent être accompagnés de la
licence freeware distincte. Aucun droit de contribution externe n'est accordé
par la publication de l'export.

Le dépôt canonique et son historique restent privés. La publication utilise un
export déterministe depuis le SHA complet approuvé de `main`, puis un dépôt Git
neuf à un seul commit. Elle reste bloquée tant que la checklist
`docs/release/PUBLIC_SOURCE_OWNER_DECISIONS.md` n'est pas satisfaite.
