# Modèle de publication open source

Le code, la documentation détenus par PriveoPDF et les exécutables officiels
sont sous Apache License 2.0 (`Apache-2.0`). `LICENSE` contient le texte intégral
et `NOTICE` les attributions du projet. Les versions déjà publiées conservent
leur licence d'origine. Les composants tiers gardent leurs licences propres.

Le nom et le logo ne sont pas couverts par la licence (section 6) ; voir
`TRADEMARKS.md`. La politique « commentaires seulement » ne change pas :
aucune contribution de code externe n'est acceptée (`CONTRIBUTING.md`).

Le dépôt canonique et son historique restent privés. La publication utilise
un export déterministe depuis un SHA complet approuvé de main vers le dépôt
public propre, sans recopier l'historique privé. Les contrôles de publication,
de confidentialité et de provenance restent applicables.
