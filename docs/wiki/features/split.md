# Diviser un PDF

## À quoi ça sert

Créer plusieurs PDF à partir d’un seul document.

## Comment faire

Ajoutez le PDF, répartissez visuellement les pages dans les groupes de sortie ou
utilisez les plages avancées, puis choisissez le dossier de destination.

## Résultat

Chaque groupe non vide devient un nouveau PDF local. Le document source reste
inchangé.

## Limites

Les groupes vides sont ignorés. Un fichier portant déjà le nom prévu n’est pas
remplacé.
