# Supprimer des pages

## À quoi ça sert

Créer une copie d’un PDF sans certaines pages.

## Comment faire

Choisissez les pages à retirer dans les miniatures ou indiquez des plages
avancées, puis sélectionnez un nouveau fichier de sortie.

## Résultat

Le nouveau PDF conserve toutes les pages non sélectionnées. L’original reste
inchangé.

## Limites

Il est impossible de supprimer toutes les pages. Une destination existante ou
identique à la source est refusée.
