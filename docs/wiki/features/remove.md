# Supprimer des pages

## À quoi ça sert

Créer une copie d’un PDF sans certaines pages.

## Comment faire

Choisissez les pages à retirer dans les miniatures ou indiquez des plages
avancées. La destination est proposée d’office dans le dossier du PDF ; **CHANGER…** permet d’en choisir une autre.

## Résultat

Le nouveau PDF conserve toutes les pages non sélectionnées. Le résultat s’affiche sous le bouton, avec **OUVRIR LE PDF**, **OUVRIR LE DOSSIER** et **CONTINUER AVEC…**.
L’original reste inchangé.

## Limites

Il est impossible de supprimer toutes les pages : le bouton reste grisé et la
raison s’affiche dessous. Un fichier existant n’est jamais remplacé.
