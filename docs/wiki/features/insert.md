# Insérer des pages

## À quoi ça sert

Ajouter dans un PDF des pages provenant d’un second PDF.

## Comment faire

Choisissez le document principal, puis le document contenant les pages à
insérer : toutes ses pages sont sélectionnées. Pour en garder moins, cliquez
sur une page, puis Ctrl+clic ou Maj+clic pour ajuster la sélection. Choisissez
la position. La destination est proposée d’office dans le dossier du document
principal ; **CHANGER…** permet d’en choisir une autre.

## Résultat

Un nouveau PDF conserve toutes les pages du document principal et ajoute la
sélection à l’endroit choisi. Le résultat s’affiche sous le bouton, avec **OUVRIR LE PDF**, **OUVRIR LE DOSSIER** et **CONTINUER AVEC…**. Les deux sources restent
inchangées.

## Limites

L’outil utilise deux PDF à la fois et conserve l’ordre des pages sélectionnées
dans le second document.
