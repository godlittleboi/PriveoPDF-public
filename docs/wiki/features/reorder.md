# Réorganiser des pages

## À quoi ça sert

Changer l’ordre des pages d’un PDF et, si nécessaire, dupliquer certaines pages.

## Comment faire

Faites glisser les miniatures dans l’ordre voulu et utilisez l’action de
duplication si besoin. La destination est proposée d’office dans le dossier du PDF ; **CHANGER…** permet d’en choisir une autre.

## Résultat

Un nouveau PDF reprend l’ordre visible et les copies demandées. Le résultat s’affiche sous le bouton, avec **OUVRIR LE PDF**, **OUVRIR LE DOSSIER** et **CONTINUER AVEC…**.
La source reste inchangée.

## Limites

Chaque page d’origine doit rester présente au moins une fois. Un document d’une
seule page n’a rien à réorganiser : le bouton reste grisé avec cette raison. Pour retirer ou
ajouter des pages venant d’un autre document, utilisez l’outil dédié.
