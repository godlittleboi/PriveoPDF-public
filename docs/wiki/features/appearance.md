# Apparence

Dans **Paramètres → Thème**, six choix sont disponibles :

- Automatique — suivre le système ;
- Sombre — Sobre ;
- Clair — Sobre ;
- Sombre — Pixel ;
- Clair — Pixel ;
- Contraste élevé.

Le mode automatique suit le thème clair ou sombre du système. Si cette
information n’est pas disponible, PriveoPDF utilise **Sombre — Sobre**.

La réduction des animations se règle également dans Paramètres. Les choix
d’apparence restent locaux et ne modifient jamais le contenu ni le rendu exporté
des PDF.
