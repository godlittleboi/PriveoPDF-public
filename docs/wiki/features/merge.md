# Fusionner des PDF

## À quoi ça sert

Réunir plusieurs PDF dans un seul document.

## Comment faire

Ouvert depuis l’accueil, l’outil reprend les **Documents ouverts** quand ils
sont 2 à 4 et lisibles ; sinon, il démarre avec le document sélectionné seul.
Ajoutez au moins deux PDF et placez-les dans l’ordre souhaité. PriveoPDF
propose d’office un fichier de sortie dans le dossier du premier PDF, par
exemple `rapport_fusionné.pdf` ; `CHANGER…` permet d’en choisir un autre. Lancez
ensuite la fusion. `Annuler` interrompt le traitement sans créer de fichier.

Un PDF protégé par mot de passe ou illisible est signalé dès son ajout, avec
son nom, et la fusion reste inactive : retirez-le, ou déverrouillez-le avec
`DÉVERROUILLER PDF`.

## Résultat

Un nouveau PDF contient les documents dans l’ordre affiché. Le résultat
s’affiche sous le bouton, avec `OUVRIR LE PDF`, `OUVRIR LE DOSSIER` et `CONTINUER AVEC…`. Les
fichiers d’origine restent inchangés.

## Limites

Un fichier existant n’est jamais remplacé : si le nom est déjà pris, PriveoPDF
propose `-2`, `-3`, etc. Certains signets ou structures complexes peuvent être simplifiés.
