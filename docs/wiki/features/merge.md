# Fusionner des PDF

## À quoi ça sert

Réunir plusieurs PDF dans un seul document.

## Comment faire

Ajoutez au moins deux PDF, placez-les dans l’ordre souhaité, choisissez la
destination puis lancez la fusion.

## Résultat

Un nouveau PDF contient les documents dans l’ordre affiché. Les fichiers
d’origine restent inchangés.

## Limites

La destination doit être différente des sources et ne doit pas déjà exister.
Certains signets ou structures complexes peuvent être simplifiés.
