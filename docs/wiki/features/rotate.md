# Faire pivoter des pages

## À quoi ça sert

Corriger l’orientation de certaines pages ou de tout un PDF.

## Comment faire

Les pages sont à gauche ; les réglages, la destination et le bouton sont dans
la colonne de droite. Tournez avec **À GAUCHE** ou **À DROITE** : chaque clic
ajoute un quart de tour et l’angle obtenu s’affiche. La cible est **Toutes les
pages** par défaut ; choisissez **Pages sélectionnées** ou **Page active** pour
la limiter. Vérifiez l’aperçu. La destination est proposée d’office dans le
dossier du PDF ; **CHANGER…** permet d’en choisir une autre. Cliquez sur
**FAIRE PIVOTER LES PAGES**.

## Résultat

Un nouveau PDF contient les rotations choisies. Le résultat s’affiche sous le bouton, avec **OUVRIR LE PDF**, **OUVRIR LE DOSSIER** et **CONTINUER AVEC…**.
Le fichier source reste inchangé.

## Limites

Seuls les angles 90, 180 et 270 produisent un fichier : à 0°, le bouton reste
désactivé et explique pourquoi, car le PDF serait inchangé. L’aperçu montre l’orientation,
mais pas une modification du contenu de la page.
