# Extraire des pages

## À quoi ça sert

Créer un nouveau PDF avec seulement les pages choisies.

## Comment faire

Sélectionnez les pages dans les miniatures et placez-les dans l’ordre voulu.
La destination est proposée d’office dans le dossier du PDF ; **CHANGER…** permet d’en choisir une autre. Lancez ensuite l’extraction.

## Résultat

Un nouveau PDF contient exactement les pages sélectionnées dans l’ordre affiché.
Le résultat s’affiche sous le bouton, avec **OUVRIR LE PDF**, **OUVRIR LE DOSSIER** et **CONTINUER AVEC…**. Le document source reste inchangé.

## Limites

Une sélection vide est refusée. Un fichier existant n’est jamais remplacé : la
destination proposée passe à `-2`, `-3`, etc.
