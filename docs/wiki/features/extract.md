# Extraire des pages

## À quoi ça sert

Créer un nouveau PDF avec seulement les pages choisies.

## Comment faire

Sélectionnez les pages dans les miniatures, placez-les dans l’ordre voulu,
choisissez la destination puis lancez l’extraction.

## Résultat

Un nouveau PDF contient exactement les pages sélectionnées dans l’ordre affiché.
Le document source reste inchangé.

## Limites

Une sélection vide est refusée. La destination ne peut pas être la source ni un
fichier existant.
