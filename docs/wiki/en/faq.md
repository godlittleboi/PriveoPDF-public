# Frequently asked questions

## Are my PDFs uploaded?

No. Reading and PDF tools work locally.

## Is the original file modified?

Not by default. A tool creates a new file and refuses to silently replace the
source.

## Where are planned features?

The home screen provides **View planned features**. This list is informational,
and its entries do not start any processing.

## Does Help work offline?

Yes. Essential pages are bundled with the application.

## Can I install extensions?

Not yet. [The Extensions page](addons/index.md) clearly separates planned work
from available features.
