# Planned extensions

Extensions cannot be installed yet.

The first planned step covers declarative resources only: themes, palettes,
redistributable fonts, stamps, templates, and styles. They cannot contain
scripts, macros, commands, or binaries.

A controlled local import must exist before any catalog. Every package will need
to state its author, version, compatibility, licenses, and checksum.

Executable extensions are a separate, later project because of their security
and maintenance risks.
