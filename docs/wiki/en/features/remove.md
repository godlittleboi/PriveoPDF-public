# Remove pages

## What it does

Create a copy of a PDF without selected pages.

## How to use it

Select pages to remove from the thumbnails or enter advanced ranges.
A destination is proposed in the PDF’s folder; **CHANGE…** lets you choose another one.

## Result

The new PDF keeps every page that was not selected. The result appears below the button, with **OPEN PDF**, **OPEN FOLDER** and **CONTINUE WITH…**.
The original remains unchanged.

## Limits

Removing every page is not allowed: the button stays greyed out with the reason
below it. An existing file is never replaced.
