# Merge PDF

## What it does

Combine several PDFs into one document.

## How to use it

Opened from the home screen, the tool takes the **open documents** when there
are 2 to 4 readable ones; otherwise it starts with the selected document alone.
Add at least two PDFs and place them in the required order. PriveoPDF proposes
an output file in the folder of the first PDF, for example
`report_merged.pdf`; `CHANGE…` lets you pick another one. Then start the merge.
`Cancel` stops processing without creating a file.

A password-protected or unreadable PDF is reported as soon as it is added, with
its name, and the merge stays disabled: remove it, or unlock it with
`UNLOCK PDF`.

## Result

A new PDF contains the documents in the displayed order. The result appears
below the button, with `OPEN PDF`, `OPEN FOLDER` and `CONTINUE WITH…`. Source files remain
unchanged.

## Limits

An existing file is never replaced: when the name is taken, PriveoPDF proposes
`-2`, `-3`, and so on. Some bookmarks or complex structures may be simplified.
