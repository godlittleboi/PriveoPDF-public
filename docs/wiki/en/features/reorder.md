# Reorder pages

## What it does

Change page order and duplicate selected pages when needed.

## How to use it

Drag thumbnails into the required order, use the duplicate action if needed,
then choose the destination.

## Result

A new PDF follows the visible order and contains the requested copies. The source
remains unchanged.

## Limits

Every original page must remain at least once. Use the dedicated tool to remove
pages or insert pages from another document.
