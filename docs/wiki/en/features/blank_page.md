# Add a blank page

## What it does

Insert an empty page at the beginning, end, or after a selected page.

## How to use it

Choose a common format or **Custom** (width and height appear only for this
format), the orientation, and the position; the page number is asked only for
**After page**. A destination is proposed in the PDF’s folder; **CHANGE…** lets you choose another one.

## Result

A new PDF contains one additional blank page. The result appears below the button, with **OPEN PDF**, **OPEN FOLDER** and **CONTINUE WITH…**. The source
document remains unchanged.

## Limits

One page is added per operation. Custom dimensions must remain between 1 and
5,080 mm.
