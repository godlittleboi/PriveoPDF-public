# Add a blank page

## What it does

Insert an empty page at the beginning, end, or after a selected page.

## How to use it

Choose a common format or custom dimensions, orientation, and position, then
select a new output file.

## Result

A new PDF contains one additional blank page. The source document remains
unchanged.

## Limits

One page is added per operation. Custom dimensions must remain between 1 and
5,080 mm.
