# Rotate pages

## What it does

Correct the orientation of selected pages or an entire PDF.

## How to use it

Choose an angle of 0, 90, 180, or 270 degrees, select the affected pages, check
the preview, and choose the destination.

## Result

A new PDF contains the selected rotations. The source file remains unchanged.

## Limits

Only the four displayed angles are accepted. The preview shows orientation but
does not edit page content.
