# Choose a tool

PriveoPDF provides sixteen tools, each associated with one simple action:

- [View PDF](view.md)
- [Merge PDF](merge.md)
- [Split PDF](split.md)
- [Extract pages](extract.md)
- [Remove pages](remove.md)
- [Reorder pages](reorder.md)
- [Rotate pages](rotate.md)
- [Insert pages](insert.md)
- [Add a blank page](blank_page.md)
- [Compress PDF](compress.md)
- [Recognize text (OCR)](ocr_pdf.md)
- [Protect PDF](protect.md)
- [Unlock PDF](unlock_pdf.md)
- [Check before sharing](share_check.md)
- [Redact PDF](redact_pdf.md)
- [Watermark PDF](watermark.md)

Features that are not available yet remain separate from these tools.
[View planned extensions](../addons/index.md).
