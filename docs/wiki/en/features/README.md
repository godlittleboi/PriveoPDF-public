# Choose a tool

PriveoPDF provides nine tools, each associated with one simple action:

- [View a PDF](view.md)
- [Merge PDFs](merge.md)
- [Split a PDF](split.md)
- [Extract pages](extract.md)
- [Remove pages](remove.md)
- [Reorder pages](reorder.md)
- [Rotate pages](rotate.md)
- [Insert pages](insert.md)
- [Add a blank page](blank_page.md)

Features that are not available yet remain separate from these tools.
[View planned extensions](../addons/index.md).
