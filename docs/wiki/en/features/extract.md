# Extract pages

## What it does

Create a new PDF containing only selected pages.

## How to use it

Select pages from the thumbnails and place them in the required order.
A destination is proposed in the PDF’s folder; **CHANGE…** lets you choose another one. Then start extraction.

## Result

A new PDF contains exactly the selected pages in the displayed order.
The result appears below the button, with **OPEN PDF**, **OPEN FOLDER** and **CONTINUE WITH…**. The source document remains unchanged.

## Limits

An empty selection is refused. An existing file is never replaced: the proposed
destination becomes `-2`, `-3`, and so on.
