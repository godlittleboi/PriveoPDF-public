# Getting started

The menu shows **PriveoPDF** separately from **PriveoPDF DEV** and the internal beta, with the official logo included in the package.

## Linux installation

The 64-bit `.deb` installer for Ubuntu 24.04 / Linux Mint 22 is undergoing
qualification and has not been published yet. It includes Python and the
application dependencies. Official downloads will appear under **Releases**,
alongside their SHA-256 checksums.

After installing a validated package, **PriveoPDF** appears in the application
menu. Package updates require installing a newer `.deb`; the development Git
updater does not apply. Removing the package preserves your documents and
preferences. Launch is refused when mandatory network isolation is unavailable.

## Open a PDF

Drop a file on the home screen or choose **View a PDF**. Once opened, the
document also appears under **Open documents**.

## Edit a PDF

1. Choose the tool that matches your goal.
2. Select the local PDF or PDFs.
3. Set the required pages or options.
4. Choose a new output file.
5. Start the operation and open the result.

See [the nine available tools](features/README.md) to choose the right workflow.
If something blocks you, open [Troubleshooting](troubleshooting.md).
