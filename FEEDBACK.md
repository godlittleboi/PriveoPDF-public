# Retours / Feedback

Merci de contribuer par un commentaire, sans envoyer de code.

| Besoin | Canal prévu | Contenu utile | À exclure |
| --- | --- | --- | --- |
| Question ou aide | Discussions — `Questions et aide` | Version, système, question précise | PDF réel, chemin personnel, secret |
| Idée | Discussions — `Idées` | Problème rencontré, résultat souhaité | Promesse de date ou code proposé |
| Interface | Discussions — `Retours sur l’interface` | Parcours, libellé, besoin d’accessibilité | Donnée personnelle dans une capture |
| Bug reproductible | Issues | Étapes minimales, attendu/observé, fichier artificiel autorisé | PDF utilisateur ou contenu confidentiel |
| Revue du code publié | Discussions — `Revue du code publié` | Commentaire ciblé sur une version et un chemin | Patch, diff, source substantielle |
| Vulnérabilité | Canal confidentiel de `SECURITY.md` | Rapport privé minimal et reproductible | Publication dans Issue ou Discussion |

Discussions ne sont pas encore activées. Le signalement privé de vulnérabilité
décrit dans `SECURITY.md` reste une gate bloquante tant qu'il n'est pas
configuré et testé ; aucune coordonnée ne doit être inventée.

Aucun commentaire ne garantit une réponse, une implémentation, un calendrier,
un paiement ou une autre contrepartie. Voir `CONTRIBUTING.md` et
`CODE_OF_CONDUCT.md`.

---

Please send comments, not code. Planned Discussions are for questions, ideas,
interface feedback, and review of published code; Issues are for reproducible
bugs; potential vulnerabilities must use the confidential route documented in
`SECURITY.md`. Do not disclose sensitive PDFs, confidential information,
personal data, credentials, unpatched vulnerabilities, patches, diffs, or
substantial source files. Feedback creates no promise of response,
implementation, schedule, payment, or other consideration.
