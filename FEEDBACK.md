# Retours / Feedback

Merci de contribuer par un commentaire, sans envoyer de code.

| Besoin | Canal | Contenu utile | À exclure |
| --- | --- | --- | --- |
| Question ou aide | Discussions | Version, système, question précise | PDF réel, chemin personnel, secret |
| Idée | Discussions | Problème rencontré, résultat souhaité | Promesse de date ou code proposé |
| Interface | Discussions | Parcours, libellé, besoin d’accessibilité | Donnée personnelle dans une capture |
| Bug reproductible | Discussions, puis Issue de suivi par le mainteneur | Étapes minimales, attendu/observé, fichier artificiel autorisé | PDF utilisateur ou contenu confidentiel |
| Revue du code publié | Discussions | Commentaire ciblé sur une version et un chemin | Patch, diff, source substantielle |
| Vulnérabilité | Canal confidentiel de `SECURITY.md` | Rapport privé minimal et reproductible | Publication dans Issue ou Discussion |

Les [Discussions publiques](https://github.com/godlittleboi/PriveoPDF-public/discussions)
sont ouvertes. Pour une vulnérabilité, suivez uniquement le canal confidentiel
de `SECURITY.md` ; ne publiez pas de détails dans Discussions ou Issues.

Aucun commentaire ne garantit une réponse, une implémentation, un calendrier,
un paiement ou une autre contrepartie. Voir `CONTRIBUTING.md` et
`CODE_OF_CONDUCT.md`.

---

Please send comments, not code. Public Discussions are for questions, ideas,
interface feedback, review of published code and reproducible bugs. Maintainers
can create tracking Issues; potential vulnerabilities must use the confidential route documented in
`SECURITY.md`. Do not disclose sensitive PDFs, confidential information,
personal data, credentials, unpatched vulnerabilities, patches, diffs, or
substantial source files. Feedback creates no promise of response,
implementation, schedule, payment, or other consideration.
